# SQL Business Case Study: Chinook Database

## Overview
This project analyzes the Chinook database (a digital music store) using SQL in MySQL Workbench. The goal is to understand sales performance, customer behavior and product trends to support data-driven decisions.

## Business Questions
- Which genres sell the most?
- Who are the high-value customers?
- How does revenue change over time?
- How do employees perform in sales?

## Tools Used
- MySQL
- MySQL Workbench

## SQL Concepts Used
JOINs, GROUP BY, aggregate functions, subqueries, ORDER BY, LIMIT

## Key Insights
- ## Key Insights
- The store generated a total revenue of $2,328.60 from 412 invoices.
- Rock is the top genre, contributing about 35% of total revenue, followed by Latin (16%) and Metal (11%).
- The top 5 customers each spent a similar amount, so revenue is spread fairly evenly across customers.
- Jane Peacock handled the highest total sales among support employees.
- The USA is the highest revenue country.
- Iron Maiden has the most albums in the store.


## How to Run
1. Download the Chinook database script (Chinook_MySql.sql).
2. Run it in MySQL Workbench to create the database.
3. Open the .sql query files in this repository and run them.
